# Terimler

## Amaç

Bu doküman, E-Ticaret Sipariş Yönetim Sistemi kapsamında kullanılan teknik ve iş terimlerinin ortak bir anlayış oluşturması amacıyla hazırlanmıştır.

---

# Terim Sözlüğü

| Terim | Açıklama |
|-------|----------|
| REST API | İstemci ve sunucu arasında HTTP protokolü üzerinden iletişim sağlayan web servis mimarisidir. |
| API | Farklı yazılımların birbiriyle iletişim kurmasını sağlayan arayüzdür. |
| Endpoint | API içerisinde belirli bir kaynağa erişim sağlayan URL adresidir. |
| Request | İstemcinin API'ye gönderdiği istektir. |
| Response | API'nin istemciye gönderdiği yanıttır. |
| HTTP Method | API üzerinde gerçekleştirilecek işlemi belirleyen yöntemdir. Örneğin GET, POST ve DELETE. |
| HTTP Status Code | API isteğinin sonucunu belirten standart durum kodlarıdır. |
| Header | HTTP isteği veya yanıtı hakkında ek bilgiler taşıyan başlık alanlarıdır. |
| Request Body | API isteği içerisinde gönderilen veri bölümüdür. |
| JSON | API veri alışverişinde kullanılan standart veri formatıdır. |
| Authentication | Kullanıcının kimliğinin doğrulanması işlemidir. |
| Authorization | Kullanıcının belirli kaynaklara erişim yetkisinin kontrol edilmesidir. |
| Bearer Token | API erişimi için kullanılan kimlik doğrulama bilgisidir. |
| OpenAPI | REST API servislerini standart bir formatta tanımlamaya yarayan spesifikasyondur. |
| Swagger | OpenAPI tanımlarını görselleştirmek ve test etmek için kullanılan araçtır. |
| Endpoint Versioning | API değişikliklerini yönetebilmek için kullanılan versiyonlama yaklaşımıdır. |
| Business Rule | Sistemin uyması gereken iş kurallarını ifade eder. |
| Functional Requirement | Sistemin gerçekleştirmesi gereken fonksiyonları tanımlar. |
| Non-Functional Requirement | Sistemin performans, güvenlik ve kullanılabilirlik gibi kalite gereksinimlerini tanımlar. |
| Use Case | Kullanıcının sistem ile gerçekleştirdiği bir iş akışını ifade eder. |
| Sequence Diagram | Sistem bileşenleri arasındaki mesajlaşma sırasını gösteren diyagramdır. |
| UAT (User Acceptance Test) | Sistemin iş ihtiyaçlarını karşıladığını doğrulamak amacıyla gerçekleştirilen kullanıcı kabul testidir. |
| Test Case | Bir sistem davranışını doğrulamak için hazırlanan test senaryosudur. |

---

# Kısaltmalar

| Kısaltma | Açılım | Açıklama |
|----------|--------|----------|
| API | Application Programming Interface | Uygulamaların iletişim kurmasını sağlayan arayüz. |
| REST | Representational State Transfer | Web servis tasarım yaklaşımı. |
| HTTP | Hypertext Transfer Protocol | Web iletişim protokolü. |
| JSON | JavaScript Object Notation | Veri alışveriş formatı. |
| UAT | User Acceptance Test | Kullanıcı kabul testi. |
| BA | Business Analyst | İş analisti. |
