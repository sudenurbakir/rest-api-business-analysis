# Proje Tanımı

## Amaç

Bu proje, örnek bir e-ticaret platformunda sipariş oluşturma ve sipariş yönetimi süreçlerini destekleyen REST API servislerinin iş analizi ve teknik dokümantasyonunun hazırlanması amacıyla oluşturulmuştur.

Çalışma kapsamında, iş gereksinimlerinden başlayarak REST API tasarımına kadar olan analiz süreci dokümante edilmektedir. Amaç; iş analisti, yazılım geliştirme ekibi ve test ekibi arasında ortak bir anlayış oluşturacak analiz çıktıları hazırlamaktır.

---

# İş Problemi

Mevcut e-ticaret sisteminde sipariş oluşturma ve sipariş yönetimi süreçlerine ait API servisleri için standart bir analiz dokümanı bulunmamaktadır.

Bu durum;

* Gereksinimlerin farklı yorumlanmasına,
* Geliştirme sürecinde iletişim problemlerine,
* Test senaryolarının eksik hazırlanmasına,
* API kullanımında tutarsızlıklara

neden olabilmektedir.

Bu proje ile REST API servislerine ait iş kuralları, gereksinimler ve teknik detaylar tek bir dokümantasyon altında toplanarak tüm paydaşlar için ortak bir referans oluşturulması hedeflenmektedir.

---

# Proje Kapsamı

Bu proje kapsamında aşağıdaki süreçler ele alınacaktır:

* Sipariş oluşturma
* Sipariş görüntüleme
* Sipariş güncelleme
* Sipariş iptali

Bu süreçlere ait REST API servisleri analiz edilerek aşağıdaki dokümanlar hazırlanacaktır:

* İş Gereksinimleri
* Fonksiyonel Gereksinimler
* Fonksiyonel Olmayan Gereksinimler
* İş Kuralları (Business Rules)
* REST API Endpoint Dokümantasyonu
* Request ve Response Yapıları
* HTTP Status Kodları
* OpenAPI (Swagger) Spesifikasyonu
* API Test Senaryoları
* User Acceptance Test (UAT)

---

# Proje Hedefleri

Bu proje ile;

* REST API servislerinin standart bir yapıda dokümante edilmesi,
* İş gereksinimlerinin teknik ekiplere açık ve anlaşılır şekilde aktarılması,
* Geliştirme ve test süreçlerinin desteklenmesi,
* API servislerinin sürdürülebilir ve tutarlı şekilde tasarlanmasına katkı sağlanması

hedeflenmektedir.
