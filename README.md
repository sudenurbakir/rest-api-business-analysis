# REST API İş Analizi Dokümantasyonu

## Proje Hakkında

Bu proje, bir **İş Analistinin (Business Analyst)** REST API geliştirme süreçlerinde hazırladığı analiz ve dokümantasyon çalışmalarını örneklemek amacıyla oluşturulmuştur.

Proje kapsamında herhangi bir yazılım geliştirme çalışması bulunmamaktadır. Amaç; iş birimleri ile yazılım ekipleri arasında köprü görevi gören İş Analistinin hazırladığı analiz dokümanlarını, API gereksinimlerini ve teknik dokümantasyonu profesyonel bir şekilde sunmaktır.

Bu çalışma, örnek bir **E-Ticaret Sipariş Yönetim Sistemi** senaryosu üzerinden hazırlanmıştır.

---

# Projenin Amacı

Bu projenin amacı, REST API süreçlerinde bir İş Analistinin sahip olması gereken analiz ve dokümantasyon yetkinliklerini uygulamalı olarak göstermektir.

Bu kapsamda;

* İş Gereksinimlerinin Analizi
* Fonksiyonel Gereksinimlerin Belirlenmesi
* REST API Analizi
* API Endpoint Tasarımı
* Request & Response Dokümantasyonu
* HTTP Methodlarının Kullanımı
* HTTP Status Code Analizi
* Authentication Yapılarının Dokümantasyonu
* Business Rules Hazırlanması
* OpenAPI (Swagger) Spesifikasyonu
* API Test Senaryoları
* Kullanıcı Kabul Testi (UAT)

konuları ele alınmaktadır.

---

# Proje Senaryosu

Bu proje, örnek bir **E-Ticaret Sipariş Yönetim Sistemi** üzerinden hazırlanmıştır.

Sistemde kullanıcılar;

* Ürünleri görüntüleyebilir.
* Ürünleri sepete ekleyebilir.
* Sipariş oluşturabilir.
* Siparişlerini görüntüleyebilir.
* Siparişlerini iptal edebilir.
* Ödeme işlemlerini gerçekleştirebilir.

Bu süreçleri destekleyen REST API servisleri analiz edilerek dokümante edilmiştir.
